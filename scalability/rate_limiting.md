# Rate Limiting

## Definition
Rate limiting restricts the number of requests a client can make within a specified period.

## Purpose
- Prevent API abuse
- Avoid DDoS attacks
- Protect backend services

## Algorithms
- Token Bucket
- Leaky Bucket
- Fixed Window
- Sliding Window

## Implementation Tools
- NGINX
- Redis
- API Gateway

## Example
100 requests per minute per user.
