# Load Balancing

## Overview
Load balancing distributes incoming client requests across multiple servers to improve performance, reliability, and availability.

## Types
- Round Robin
- Least Connections
- IP Hash
- Weighted Round Robin

## Benefits
- High Availability
- Fault Tolerance
- Better Resource Utilization
- Reduced Response Time

## Popular Load Balancers
- NGINX
- HAProxy
- AWS Elastic Load Balancer
- Azure Load Balancer

## Best Practices
- Enable health checks.
- Configure SSL termination.
- Monitor backend server health.
