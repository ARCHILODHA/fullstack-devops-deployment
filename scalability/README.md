# Employee Management System

The Employee Management System is a web-based application developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript.

## Features
- Employee Registration
- Secure Login
- Dashboard
- Profile Management
- Attendance Tracking
- Leave Management
- Salary Records

## Technologies Used
- Java
- JSP & Servlets
- JDBC
- MySQL
- HTML, CSS, JavaScript
