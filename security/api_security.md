# API Security

## Overview
API security protects REST, GraphQL, and gRPC endpoints from unauthorized access and attacks.

## Best Practices
- Use HTTPS for all endpoints.
- Implement OAuth 2.0 or JWT authentication.
- Validate all user inputs.
- Enable rate limiting.
- Restrict CORS origins.
- Hide sensitive error messages.

## Common Threats
- Broken Authentication
- SQL Injection
- API Abuse
- Mass Assignment
- Rate Limit Bypass

## Recommended Tools
- Postman
- OWASP ZAP
- Burp Suite
- API Gateway

## Checklist
- HTTPS Enabled
- Authentication Implemented
- Authorization Verified
- Input Validation
- Logging Enabled
