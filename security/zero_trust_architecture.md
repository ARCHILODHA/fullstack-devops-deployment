# Zero Trust Architecture

## Introduction
Zero Trust is a security approach that assumes no user, device or network should be automatically trusted.

Every access request must be evaluated.

## Core Principles

1. Verify explicitly.
2. Use least-privilege access.
3. Assume breach.
4. Continuously monitor access.
5. Validate identity and device context.

## Components

- Identity management.
- Multi-factor authentication.
- Access policies.
- Device security.
- Network segmentation.
- Monitoring.
- Risk-based authentication.

## Example Workflow

1. User requests access to a service.
2. Identity is verified.
3. Device posture is evaluated.
4. Access policy is checked.
5. Least-privilege access is granted.
6. Activity is monitored.

## Benefits

- Reduces implicit trust.
- Limits lateral movement.
- Improves access control.
- Supports remote workforce security.
- Improves visibility.

## Implementation Practices

- Use MFA.
- Apply role-based access control.
- Segment networks.
- Monitor access logs.
- Protect service identities.
- Review permissions regularly.

## Conclusion
Zero Trust improves security by continuously validating access instead of relying on network location alone.
