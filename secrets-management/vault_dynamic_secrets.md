# Vault Dynamic Secrets

## What are Dynamic Secrets?

Dynamic secrets are credentials generated by Vault on demand.
They are temporary and automatically expire after a configured TTL.

Example:
- Database usernames/passwords
- AWS IAM credentials
- Azure credentials
- GCP service accounts

## Advantages

- No hardcoded passwords
- Short-lived credentials
- Automatic revocation
- Better security

## Example

Application
     ↓
HashiCorp Vault
     ↓
Generate DB User
     ↓
Return Temporary Credentials

## Benefits

- Reduced credential leakage
- Easier auditing
- Automatic cleanup
