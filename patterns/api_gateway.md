# API Gateway Pattern

## Overview
An API Gateway acts as a single entry point for all client requests in a microservices architecture.

## Responsibilities
- Authentication
- Authorization
- Routing
- Rate Limiting
- Logging

## Advantages
- Centralized security
- Simplified clients
- Better monitoring

## Disadvantages
- Single point of failure
- Increased complexity

## Use Cases
- Netflix
- Amazon
- Kubernetes Ingress
