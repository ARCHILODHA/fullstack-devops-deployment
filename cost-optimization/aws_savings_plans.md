# AWS Savings Plans

## Overview

Savings Plans provide discounted pricing in exchange for consistent AWS usage.

## Types

### Compute Savings Plan

Applies to:

- EC2
- Lambda
- Fargate

### EC2 Instance Savings Plan

Applies to a specific instance family.

## Benefits

- Up to 72% savings
- Flexible pricing
- Automatic discounts

## Best Practices

- Analyze historical usage.
- Purchase only stable workloads.
