# Amazon RDS Cost Optimization

## Overview

Optimize Amazon RDS to reduce database costs.

## Techniques

- Right-size database instances.
- Stop development databases when unused.
- Purchase Reserved Instances.
- Enable storage autoscaling.
- Delete unused snapshots.

## Monitoring

Use CloudWatch metrics:

- CPU Utilization
- Connections
- Free Storage
- Read/Write IOPS

## Benefits

- Lower database expenses
- Better utilization
