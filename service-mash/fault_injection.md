# Fault Injection

## What is Fault Injection?

Fault Injection intentionally introduces failures into a system to test resilience.

---

## Purpose

- Test application behavior
- Verify recovery mechanisms
- Improve reliability

---

## Types

- Delay Injection
- HTTP Error Injection
- Connection Failure

---

## Benefits

- Detect weak services
- Validate retry policies
- Improve disaster readiness
