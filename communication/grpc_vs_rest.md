# gRPC vs REST

## REST
REST uses HTTP methods like GET, POST, PUT, and DELETE.

### Features
- Human-readable JSON
- Easy integration
- Browser friendly

## gRPC
gRPC uses Protocol Buffers for fast communication.

### Features
- High performance
- Strong typing
- Supports streaming

## Comparison

| Feature | REST | gRPC |
|--------|------|------|
| Format | JSON | Protobuf |
| Speed | Moderate | Fast |
| Streaming | Limited | Native |
| Browser Support | Excellent | Limited |

## Conclusion
REST is ideal for public APIs, while gRPC suits microservices communication.
