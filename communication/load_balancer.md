# Load Balancer

## What is Load Balancing?
Distributes incoming traffic across multiple servers.

## Types
- Layer 4 Load Balancer
- Layer 7 Load Balancer

## Algorithms
- Round Robin
- Least Connections
- IP Hash

## Benefits
- High availability
- Fault tolerance
- Improved performance

## Popular Tools
- HAProxy
- NGINX
- AWS ELB
