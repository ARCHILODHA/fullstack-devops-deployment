# Logging Best Practices

## Purpose

Logging records application events for troubleshooting.

## Good Practices

- Log meaningful messages
- Use timestamps
- Include request IDs
- Avoid sensitive data
- Rotate log files

## Log Levels

INFO

General information

WARNING

Potential issues

ERROR

Application failures

DEBUG

Detailed troubleshooting

## Example

2026-07-11 10:20:15 INFO User logged in successfully
