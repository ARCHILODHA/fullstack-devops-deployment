# Chaos Engineering

## What is Chaos Engineering?

Chaos Engineering intentionally introduces failures into a system to test resilience.

## Objectives

- Discover weaknesses
- Improve recovery
- Validate redundancy
- Build confidence

## Popular Tools

- Chaos Monkey
- LitmusChaos
- Gremlin

## Example

Stop one server intentionally.

Expected Result:
Application continues working without downtime.
